# 离线 OCR 的可撤上下文注意力

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

查询、键和值是有限实数向量。分数为 q·k / sqrt(d)，输出为按可见键做稳定 Softmax 后的加权值，空域单独表示。键身份为 (票据 ID, 栏 ID, word)，相同身份较高修订取代旧值。修订是票据级递增整数，撤回列从生效修订起移除列内旧键，清空列边界动作只改变可见列集合，不清空键。query 的版本与可见列相结合。结果绝对误差不超过 1e-6，输入块与调用方已领取的输出不计入工作内存，内部投影、分数和缓存均计入。 当前票据任一有效修订前进都使未确认的旧修订请求不能确认。撤回只清除所指的列，清空列边界则取消页面当前可选列范围的限制，已经撤回的键仍不可见。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。keys 选记录的半开下标范围；withdraw 给出票据、栏和撤回生效修订。query、confirm、retry 以查询 ID 引用。
