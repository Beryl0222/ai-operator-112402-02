# 异构 NPU 的不对称 INT4 跨通道反量化矩阵乘

这里的矩阵片段和码字是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

输入 A 是 u8，按行量化，W 是列主序二补数 int4，低半字节先。每列末 nibble 若因 K 为奇数成为填充，必须为零。尺度为整数乘以 2 的整数次幂，偏置与残差也是二进制有理数。参考表达式先对实值乘积精确求和、加偏置及残差，再按设备舍入一次并夹到 i8。N1 每片原始中心化乘积的精确累加落在 signed 16 位界；N2 为 signed 24 位。输出前的定点移位，N1 最接近且平局向偶，N2 最接近且平局远离零。设备片段为 [rowStart,rowEnd,columnStart,columnEnd,kStart,kEnd,group,accumulatorWidth]，边界半开列单元不可拆，分组边界为 groupCuts；宽度必须和该档一致。设备输入字节细节在 wire 中，设备端不能读取已解包的完整权重。实际中心化乘积累计及抗溢出证明可为数据相关或对合同范围成立。设备工作区包含解包/重排及待合并的硬件结果。 两种窄位宽限制每个片段的任何前缀，包含最终累加。residual 的名义位置与具体输出一致，输入量化 scale 默认 1。相同权重可供任意多输入行，bad nibble 拒绝所在物理权重列和依存输出，缺激活片拒绝对应行。无效的包形状、分组跨度或编码版本拒绝整个包。 format 是固件包容器。tag 正好两个 ASCII 字节，随后是四个无符号 32 位字段。每片索引同宽，payload 所在的全矩阵权重列顺序不可改变。重复的数据档可引用同一权重字段，任何片段所需的运行时值由同时到达的激活和 weight 码解释。

## 取数

`inputs/int4-wire.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。int4Activation(row,variant) 给设备激活行，int4Column(column,failure) 给单列打包权重，failure 打开坏填充记录。
